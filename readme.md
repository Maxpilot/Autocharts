Background Script for Falcon BMS

This background script is designed to be used with Falcon BMS in conjunction with:

1. OpenKneeboard
2. The need to switch the default Windows audio input and output devices


OpenKneeboard

The script monitors the briefing file in the Falcon BMS folder. As soon as the file is modified (by clicking "Print" in Falcon BMS), the following actions are performed:
1. The charts for the departure, arrival, and alternate airports are transferred to OpenKneeboard.
2. The briefing is converted into a clearly structured PDF file and also transferred to OpenKneeboard.
3. The last two-page spread of the original Falcon BMS kneeboard is transferred to OpenKneeboard.
The third item is intended to allow a data card generated by the Weapon Delivery Planner to be transferred to OpenKneeboard.


Switching the Default Audio Input and Output

By pressing F4 (the key must not be assigned to another function in Falcon BMS), the Windows default audio input and output devices are switched.
This makes it possible to quickly switch between different headsets or audio devices by simply pressing F4, for example between a regular headset and a VR headset.

Configuration:
The individual IDs of the input and output devices must be configured in the code. Custom folder paths are specified in the .ini file.
